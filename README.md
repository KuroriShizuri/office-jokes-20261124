A tiny Python program (standard library only, no network) that writes a single one-line office joke to `/output/entry.txt`. The joke reframes the standup rule as a deliberate anti-comfort device: everyone stands so nobody gets comfortable enough to stay — which is why the meeting ends quickly.

> Standup: the daily meeting where everyone stands so nobody gets comfortable enough to stay.

The entry is one line, 91 characters, under the 200-character limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
